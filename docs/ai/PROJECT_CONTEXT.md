# GushiOS V2 项目上下文

广州固实内部经营协作平台，面向中国建材及制造业员工。优先减少录入、及时跟进、避免项目遗漏，再连接采购、交付与资金风险；中文、手机可用、服务端权限和财务准确性优先。

## 权限与业务
三个主入口：销售、管理、财务。保留 sales/management/operations/aftersales/finance 五类授权范围及技术、物流等岗位身份。运营和售后进入管理入口不等于获得管理权限。分部不再作为权限边界，旧字段保留。
销售仅访问正式归属 memberId 的项目和必要商务字段；转交后只保留本人任期结果快照，不能读取当前项目、合同、群聊或附件。管理查看公司业务、默认只读财务；财务查看公司项目并维护收付，不任意改销售记录。历史私人消息不因管理身份开放。
项目只需名称即可创建，销售自动绑定本人；跟进只需文字、日期选填，独立追加，普通编辑不算跟进。暂停/丢单必须原因并留历史，暂停进入管理复查。任务、消息、报价、合同、销售考核等现有能力保留。

## 架构与数据
Next.js App Router、React、TypeScript；自托管 Node 24+、SQLite，保留 Cloudflare/D1 适配。db/schema.ts 与 drizzle SQL 迁移；服务端 API 经身份、工作台范围、项目与字段权限检查。projects 关联成员、跟进、结果事件、任务、群聊与 finance_books；公司费用、核销与凭证沿用现有财务模型，详见 ARCHITECTURE.md。
金额为整数分；合同金额、确认计划、实际到账分开。草稿不算正式应收，部分支付只预测余额，结清不因编辑重开。采购批次、报销、工资和固定支出联动13周情景预测，不连接真实银行转账。
